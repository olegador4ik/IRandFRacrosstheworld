The map depict the relativity of fertility and migration rates across the worldwide countries in 2026.

The script parses statistics population data from https://www.worldometers.info/world-population/population-by-country/
and generate it into the map from generated configuration 

1. Execute parsing.py, be sure you've received result.txt
2. Go to https://www.mapchart.net/world-advanced.html
3. Click on "Save/Load map configuration" and load ("result.txt")
